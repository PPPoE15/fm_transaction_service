# FM-96: упрощение CSV — план реализации backend

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** выполнить backend-часть FM-96 в fm_transaction_service.
**Architecture:** CSV-адаптер определяет разделитель по заголовку, сопоставляет поля по именам и сохраняет физические номера строк. Нормализация CSV изолирована от существующих правил XLSX. Атомарный обработчик импорта остаётся общим.
**Tech Stack:** Python, csv, pytest, FastAPI, Postgres.
**Spec:** PPPoE15/fm-auto-dev#96 (шесть требований пользователя).

## Global Constraints
- Только CSV: порядок и дополнительные столбцы произвольны, обязательные заголовки уникальны.
- UTF-8, запятая и точка с запятой, Unicode strip всех значений.
- День и месяц — две ASCII-цифры, год — две либо четыре; 00–99 соответствует 2000–2099. Любой нецифровой разделитель даты.
- Ошибки адресуются физической строкой начала записи. Лимиты и атомарность сохраняются.
- Русские docstring у всех новых функций и методов.

## Review Focus
- Разделитель внутри кавычек и заголовков дополнительных столбцов не меняет определение CSV.
- Несколько физических строк в записи не сдвигают адрес следующей ошибки.
- Отсутствующие поля и дублирующиеся заголовки не допускают неверного сопоставления.
- Очень широкие и длинные записи остаются ограничены размером файла.
- Новая нормализация не меняет XLSX, число операций или сохранение при ошибках.
